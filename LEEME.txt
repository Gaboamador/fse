FSE FRONTEND CLEANUP PATCH

Objetivo
--------
Dejar el frontend Cloudflare-only y eliminar artefactos del motor local/benchmarks,
sin tocar App.jsx ni romper "Ver capítulo completo".

1. Copiá el contenido de este ZIP sobre:
   C:\Users\amadorg\Documents\pprog\friends-search-engine

   Reemplazá los archivos cuando Windows lo pregunte.

2. Desde PowerShell, parado en la raíz del proyecto, ejecutá:

   powershell -ExecutionPolicy Bypass -File .\cleanup-obsolete.ps1

El script:
- ABORTA antes de limpiar public\data si no encuentra public\data\friends-corpus.json.
- elimina dist, benchmark, data, scripts y src\search\search.worker.js;
- dentro de public\data conserva SOLAMENTE friends-corpus.json;
- no toca cloudflare-worker;
- no toca node_modules.

Cambios funcionales
--------------------
- searchClient.js queda Cloudflare-only.
- App.jsx queda intacto.
- SearchResult.jsx mantiene la misma estructura de escenas/speakers/transcript.
- El corpus completo se sigue cargando sólo al usar "Ver capítulo completo".
- La URL del corpus usa import.meta.env.BASE_URL para que funcione también bajo
  un base path de GitHub Pages.
- se elimina @huggingface/transformers y prepare:assets.
- vite.config.js ya no contiene config de Web Worker.
- dist sigue siendo generado; no se conserva/versiona.

Después de aplicar
------------------
Ejecutá:

  npm install
  npm run build

Luego revisaremos el nuevo dist antes del deploy público.
